<h2>🚀 About Me</h2>

<p>
  I'm Shivani Sharma, a developer working across
  <strong>software, web, games and AI</strong>.
  I build responsive websites, interactive 3D experiences and Unity games,
  and use reinforcement learning to explore how autonomous agents learn
  and work together.
</p>

<ul>
  <li>
    💻 <strong>Software &amp; web:</strong>
    React applications, real-time 3D environments and interactive tools
    with Three.js and React Three Fiber.
  </li>
  <li>
    🎮 <strong>Games:</strong>
    Gameplay systems, couch co-op mechanics and VR experiences
    built with Unity and C#.
  </li>
  <li>
    🧠 <strong>AI:</strong>
    Multi-agent reinforcement learning, autonomous UAV coordination
    and trained game behaviours using Unity ML-Agents, Python and PyTorch.
  </li>
  <li>
    🎓 <strong>Education:</strong>
    MSc Game Development (Programming) with Distinction ·
    First-Class BSc (Hons) Game Design.
  </li>
</ul>
